Catch the drift before it starts

behaviornudge reads what is already recorded on this Mac, finds the moments when a purposeful visit to LinkedIn, X or Instagram turned into feed-scrolling, and tests which model predicts those moments early enough to nudge. Everything runs locally; only short activity keys and trimmed titles go to two cloud services.

The trap, and where the nudges go

A drift episode starts with a purposeful visit and counts as drift when at least 3 minutes of off-task consuming follow within 15 minutes, before you return to work for at least 60 seconds.

Open decision

The BehaviorGPT SDK re-stamps history events with times just before "now", so the model would read the wrong hour and weekday for past episodes. The raw API it calls accepts a real timestamp per event and an as-of time per request.

  • Recommended: call that endpoint directly with real timestamps
  • Use the SDK and accept "now" times (time-of-day signal lost)
  • Only score recent episodes
