One click teaches it

Every nudge has four buttons. Your answers change when, and whether, the next one comes.

Back to task
The nudge helped. It counts toward the return-to-work rate.
Too soon
Next time, this kind of nudge waits 1.5× longer in the same context.
Legit task
This activity counts as on-task for this task from now on, both live and in backtests.
Snooze 30 min
Pauses all nudges for half an hour.

How it decides

Rules decide when to nudge. A model sorts your activity into kinds, and another model is being tested on whether it can predict drift.

  1. Watch

    It reads the screen-activity history your Mac already records with Retrace, plus the front app, the browser tab, whether a call has the mic, and herdr agent status.

  2. Label

    Rules label most activities, and TypeSafe Jev labels the unclear rest, as one of:

    creativereactiveconsuming

  3. Compare

    It checks what you're doing against what you planned (Sunsama timer, timebox or calendar) and fires at the moments where drift starts, with a cooldown and a daily limit.

  4. Predict

    Unbox AI's BehaviorGPT scores each moment in shadow mode. In the backtest it beat a baseline built from your own history in 18 of 28 weeks, though both signals are still weak. How BehaviorGPT is used →

Tune every nudge

Timings, the daily budget, cooldowns, quiet hours, the sound for each nudge, which calendars count and which sites are drift-prone are all lines in one file, behaviornudge.toml.

Every setting, explained → 
[nudge]
daily_budget = 8
cooldown_min = 15          # per type and site
quiet_hours = [["21:30", "07:00"]]
feed_arrival_delay_s = 45
off_task_threshold_min = 8
too_soon_factor = 1.5     # after "Too soon"

[nudge.sounds]
arrival = "Tink"
off_task = "Sosumi"
in_call = "none"        # silent in calls

Built on the history your Mac already keeps

behaviornudge doesn't record your screen. It reads, read-only, what a screen-history app already stores: Retrace.to, where it started, and jhammant's open-source Retrace, which it uses now, with Screen Time, browser history and your calendar.

How capture works →

Retrace by jhammantlive captures with on-device captions, Screen Time, browser history, calendar

Private by design

  • Your screen stays on your Mac. Screen text, URLs and screenshots never leave it.
  • What it sends is limited and logged. Only activity keys and trimmed titles go out, through an allowlisted gate that logs every request.
  • It never listens to calls. Call detection only checks which call apps are using the microphone.
  • The source is open under the MIT license, so you can read exactly what it does.
